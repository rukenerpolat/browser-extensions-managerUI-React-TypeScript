## Features

– **Extension Management:** Easily toggle extensions between `active` and `inactive` states with a single click.  
– **Smart Filtering:** Quickly sort and view extensions based on their current status (Active vs. Inactive).  
– **Dynamic List Control:** Capability to remove unwanted extensions from the dashboard.  
– **Customization:** Personalize the interface by selecting preferred color themes.  
– **Responsive Design:** Optimized layout that adapts perfectly to various screen sizes, from mobile devices to large desktop monitors.  
– **Interactive UI Elements:** See hover and focus states for all interactive elements on the page.  
– **Data-Driven:** Demonstrates state management using a local `data.json` file.

## Installation

1. Clone the repository:

   ```
   git clone https://github.com/rukenerpolat/browser-extensions-managerUI-React-TypeScript.git
   ```

2. Navigate to the project directory:

   ```
   cd browser-extensions-managerUI-React-TypeScript
   ```

3. Install the dependencies:

   ```
   npm install
   ```

4. Start the development server:

   ```
   npm run dev
   ```

5. The app will run at `localhost`
